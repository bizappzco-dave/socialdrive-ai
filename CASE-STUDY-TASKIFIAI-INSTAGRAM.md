## Lessons Learned (For Internal Use)

### What Worked Well
- ✅ Using "David" as persona (real founder = more trust)
- ✅ Plain Irish English (no jargon, no corporate speak)
- ✅ 20 specific FAQs (not generic templates)
- ✅ Clear handover triggers (AI knows when to escalate)
- ✅ Comment-to-DM automation (converts passive engagers)

### What We'd Do Differently
- ⚠️ Start with fewer keyword triggers (5, not 10)
- ⚠️ Test inbound flow first (before outbound outreach)
- ⚠️ Add more "exit ramps" (no pressure, easy to decline)
- ⚠️ Create video tutorial for clients (how to use dashboard)

### Common Client Questions (Prepare Answers)
- "Will it sound like me?" → Yes, we train on your brand voice
- "What if it says something wrong?" → AI flags uncertain responses for review
- "Do I need to approve every post?" → Only first 2 weeks, then optional
- "What if I don't like a post?" → We revise instantly, no charge
- "How do I track ROI?" → Weekly report shows bookings + revenue
