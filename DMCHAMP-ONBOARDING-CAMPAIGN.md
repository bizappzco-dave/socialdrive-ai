# DM Champ Onboarding Campaign

**Campaign Type:** Automated new client onboarding  
**Product:** Social-Chats AI + Social-Drive AI  
**Goal:** Collect brand profile, get client uploading, first posts live in 48 hours  
**Tone:** Warm, supportive, clear (no jargon)

---

## Campaign Overview

### Timeline

| Day | Action | Purpose |
|-----|--------|---------|
| **Day 0** | Welcome message (immediate) | Set expectations, build confidence |
| **Day 1** | Questions 1-4 (brand basics) | Start easy, build momentum |
| **Day 2** | Questions 5-8 (audience + voice) | Deep dive into positioning |
| **Day 3** | Questions 9-12 (competitors + prefs) | Complete brand profile |
| **Day 4** | Upload token + instructions | Enable content submission |
| **Day 7** | Check-in ("How's it going?") | Offer support, remove blockers |
| **Day 10** | First posts preview | Get approval before publishing |
| **Day 14** | "Going live tomorrow!" | Build excitement |
| **Day 15** | First posts published | Celebrate milestone |
| **Day 28** | Month 1 complete + testimonial | Request feedback, case study |

## DM Champ Configuration

### Campaign Settings

| Setting | Value |
|---------|-------|
| **Campaign Name** | "New Client Onboarding" |
| **Trigger** | Payment confirmed / contract signed |
| **Goal** | Client uploading + first posts live |
| **Sending Window** | 10:00 AM (client's local time) |
| **Follow-up** | Enabled (see fallback messages above) |
| **Exit Condition** | Month 1 complete (Day 28) |

### Custom Fields to Track

| Field | Type | Purpose |
|-------|------|---------|
| `client_name` | Text | First name |
| `business_name` | Text | Official business name |
| `onboarding_day` | Number | Current day (0-28) |
| `questions_completed` | Number | How many of 12 questions answered |
| `photos_uploaded` | Number | How many photos uploaded |
| `posts_approved` | Number | How many posts approved |
| `posts_live` | Number | How many posts published |
| `upload_token` | Text | Secure upload token |
| `dashboard_url` | Text | Client dashboard link |
| `testimonial_requested` | Boolean | Has testimonial been requested? |
| `testimonial_received` | Boolean | Has testimonial been received? |

### Webhook Triggers

| Event | Action |
|-------|--------|
| `payment_confirmed` | Start Day 0 welcome message |
| `questions_completed` | Send Day 4 upload instructions |
| `photos_uploaded` | Notify David (start post generation) |
| `posts_approved` | Schedule posts, send Day 14 message |
| `posts_live` | Send Day 15 celebration, track engagement |
| `day_28_reached` | Send testimonial request |
